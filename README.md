# prototype-nybeauty (Rosélia Atelier)

> Luxury E-Commerce Front-End Prototype & Interactive Omnichannel Mockup for Modern Beauty Supply & Extension Bar.

## ✨ Highlights
- **Curated Beauty Supply Catalog**: 2,480+ SKUs across Hair Care, Wigs & Extensions, Skincare, Makeup, and Tools & Accessories.
- **Simulated Toast POS Real-Time Inventory**: Live stock badges (🟢 In Stock, 🟠 Low Stock, 🔴 Out of Stock), restock alerts, and 1-hour in-store pickup guarantee.
- **"Verify Before Fulfillment" Pre-Authorization Workflow**: Zero-overselling architecture preventing double-sales when physical store walk-ins buy items off the shelf.
- **Micro-Interactions & Seamless SPA Transitions**: Built with modern CSS3 variables, fluid `cubic-bezier(0.22, 1, 0.36, 1)` page and category department transitions, and glassmorphic slide-over drawers.
- **Executive Strategy & Architecture Blueprint**: Interactive modal with deep-dive recommendations for Shopify/WooCommerce, Toast POS sync bridges (SKU IQ, Nash), and live POS register simulation.

## 🚀 Live Deployment
- Static web application ready for Vercel, Netlify, or GitHub Pages. Zero build step required.
